# 문구 규칙: 사람이 쓴 것처럼, 친근하게

> 2026-11-12 처음 정함. 2026-11-13 자료조사와 본문 진단으로 보강.
> 레슨, 용어 사전, 캡션, 버튼, 안내문 등 사이트의 모든 글에 적용한다.
> 검사는 `npm run copy:lint`. 마지막에는 꼭 소리 내어 읽어 본다.

## 0. 왜 어색하게 읽히나

한국어 글의 AI 티는 낱말보다 어미, 문장 구조, 글 모양에 붙어 있다. 낱말 몇 개를 바꿔서는 고쳐지지 않는다.

아직 손대지 않은 레슨 본문(약 12만 6천 자)을 세어 보니 이렇게 나왔다.

| 패턴 | 건수 | 이 문서의 규칙 |
|---|---|---|
| 굵은 글씨 | 848 | 글 모양 1 |
| 줄표(—) | 434 | 문장 5, 글 모양 2 |
| 문장 안의 화살표(→) | 277 | 글 모양 3 |
| 괄호 영어 병기 | 188 | 글 모양 4 |
| 합니다체 안에 섞인 해요체 | 70여 | 말투 |
| "~적", "~적인" | 89 | 문장 12 |
| 같은 어미 세 번 연속 | 18 | 문장 14 |

가장 많이 걸리는 것은 낱말이 아니라 글 모양이다. 굵은 글씨, 줄표, 화살표, 괄호가 겹치면 문장이 멀쩡해도 기계가 쓴 글처럼 보인다.

## 1. 말투

- **초급과 화면 문구(버튼, 안내, 위젯)는 해요체.** "눌러 보세요", "잘 어울려요".
- **중급과 고급 본문은 합니다체.** 다만 딱딱한 문어체 낱말은 쓰지 않는다.
- 한 레벨 안에서 말투를 섞지 않는다. 합니다체 본문에 "~죠", "~거든요", "~잖아요"를 끼우지 않는다.
  - ✗ 비율이 20:1 이상이라 천장 위로는 거의 통과시키지 않죠.
  - ○ 비율이 20:1 이상이라 천장을 넘는 신호는 거의 지나가지 못합니다.
- 권하는 말 "~해 보세요"는 어느 레벨에서나 쓴다. 합니다체 본문에 "~해 보십시오"를 쓰면 오히려 딱딱하다.
- 중급과 고급의 `Callout`(직접 해 보기 안내)은 화면 문구로 보고 해요체를 써도 된다. 본문 문단은 합니다체로 둔다.
- 독자를 "여러분", "당신"으로 부르지 않는다. 주어는 빼도 뜻이 통하면 뺀다.
- 묻고 답하지 않는다. "왜 ~일까요?"로 시작해서 바로 답하는 문장은 답을 바로 쓴다.
  - ✗ **왜 킥과 베이스는 가운데일까요?** 저음은 에너지가 커서…
  - ○ 킥과 베이스는 가운데에 둡니다. 저음은 에너지가 커서…

## 2. 문장

1. **한 문장에 한 가지만.** 길어지면 둘로 나눈다. "~하고", "~하며"로 세 덩이 이상 잇지 않는다.
2. **서술어로 끝낸다.** "밝고 안정적.", "직각으로 잘라냄."처럼 명사나 어간으로 끊지 않는다. `DefCard` 본문도 문장이다. 제목, 라벨, 표의 칸만 예외.
   - ✗ 한계에서 직각으로 잘라냄. 날카롭고 공격적.
   - ○ 신호가 한계에 닿으면 직각으로 잘립니다. 날카롭고 거친 소리가 납니다.
3. **사실을 먼저 말한다.** 무엇이 어떻게 들리는지, 무엇을 누르면 되는지. 비유는 꼭 필요할 때 하나만 쓰고, 비유로 문단을 열지 않는다.
   - ✗ 같은 사람도 정장을 입으면 진지해 보이고, 운동복을 입으면 활발해 보이죠. 음악도 … 그 옷이 바로 **편곡**이에요.
   - ○ 같은 코드와 멜로디라도 편곡을 바꾸면 장르가 바뀌어요.
4. **양쪽을 같은 틀로 맞추지 않는다.** "가까우면 부드럽게, 멀면 색다르게" 같은 대구는 두 문장으로 풀어 쓴다.
5. **줄표(—)로 문장을 잇지 않는다.** 마침표로 끊거나 "은/는", "이라서"로 잇는다.
6. **번역투를 쓰지 않는다.**

   | 쓰지 않는 표현 | 바꿔 쓰기 |
   |---|---|
   | ~를 통해 | ~로, ~해서 |
   | ~에 대해, ~에 대한 | ~을, ~의 |
   | ~에 있어서, ~함에 있어 | ~할 때, ~에서 |
   | ~에 의해 ~된다 | ~이 ~한다 (하는 쪽을 주어로) |
   | ~되어진다, 보여진다 | ~된다, 보인다 |
   | ~하는 것이 가능하다 | ~할 수 있다 |
   | ~라고 볼 수 있다, ~라고 할 수 있다 | ~이다 |
   | ~를 가지고 있다 (성질, 특징) | ~이 있다, ~하다 |
   | ~에서의, ~로의 | 풀어 쓴다 ("한 주파수에서의 보강" → "한 주파수의 보강") |
   | ~중 하나이다 | 뺀다 ("대표적인 이펙트 중 하나입니다" → "자주 쓰는 이펙트입니다") |

   "~되다" 자체는 우리말이다. 하는 쪽이 분명할 때만 능동으로 바꾸고, "코드가 된다", "소리가 바뀌게 된다"처럼 자연스러운 것은 그대로 둔다.
7. **상투적인 맺음말을 쓰지 않는다.** "결론적으로", "종합하면", "살펴보았습니다", "시사하는 바", "주목할 만하다". 문단 끝에서 앞의 말을 한 번 더 요약하지 않는다.
8. **"~할 수 있어요/있습니다"를 연달아 쓰지 않는다.** 한 문단에 한 번. "~할 수 있을 것으로 보인다"처럼 완곡을 겹치지 않는다.
9. **셋으로 맞추지 않는다.** 예시나 장점이 둘이면 둘만, 넷이면 넷을 쓴다.
10. **"A가 아니라 B" 대구는 정말 헷갈리는 둘을 가를 때만.** 독자가 A를 떠올리지도 않았으면 B만 쓴다.
    - ✗ 곡의 에너지는 볼륨이 아니라 밀도로 만듭니다.
    - ○ 곡의 에너지는 밀도로 만듭니다. 파트 수, 리듬, 음역을 쌓고 뺍니다.
11. **쉬운 동사를 쓴다.** "~로 기능합니다", "~의 역할을 합니다", "~를 담당합니다", "~에 해당합니다"는 "~입니다", "~합니다"로 줄인다.
    - ✗ 빠진 소리가 무엇을 담당하고 있었는지 드러납니다.
    - ○ 빠진 소리가 무엇을 하고 있었는지 들립니다.
12. **"-적", "-의", "것", "들"을 덜어 낸다.** 빼도 뜻이 같으면 뺀다. "-의"가 한 구에 두 번 이어지면 고친다. "~하는 것이 중요합니다"는 "~해야 합니다" 또는 그냥 "~합니다".
13. **잡초를 뽑는다.** 빼도 뜻이 같은 말은 뺀다: 바로, 사실, 정말, 매우, 아주, 앞으로, 다양한, 효과적으로, 강력한, 핵심. 남겨야 하면 구체적인 말로 바꾼다 ("다양한 이펙트" → "딜레이와 리버브").
14. **리듬을 섞는다.** 같은 어미가 세 번 이어지면 하나를 바꾼다. 모든 문장이 비슷한 길이면 짧은 문장을 하나 넣는다. 문두 접속어("또한", "따라서", "즉", "나아가")를 연달아 쓰지 않는다.
15. **같은 대상을 다른 말로 바꿔 부르지 않는다.** 한 번 "옆 칸"이라고 했으면 끝까지 "옆 칸"이다. 반복을 피하려고 낱말을 바꾸는 습관이 가장 큰 AI 티다. 아래 「4. 낱말」을 따른다.

## 3. 글 모양

1. **굵은 글씨는 문단에 하나.** 처음 나오는 용어나 눌러야 할 버튼 이름에만. 문장이나 구절 전체를 굵게 하지 않는다. 강조하고 싶으면 그 내용을 문장 앞으로 옮긴다.
2. **"용어 — 설명" 글머리표를 쓰지 않는다.** `- **엔벨로프 vs LFO** — 둘 다 …` 꼴은 두 가지로 바꾼다.
   - 항목이 셋 이상이고 정의를 나열하는 것이면 `DefList`와 `DefCard`.
   - 아니면 그냥 문단으로. 용어를 주어로 쓴다.
   - ✗ - **엔벨로프 vs LFO** — 둘 다 변조원이지만 성격이 다릅니다. 엔벨로프는 트리거당 **한 번** 지나가는 일회성 윤곽, LFO는 계속 **반복**하는 주기 신호입니다.
   - ○ 엔벨로프와 LFO는 둘 다 변조원입니다. 엔벨로프는 건반을 누를 때마다 한 번 지나갑니다. LFO는 멈추지 않고 되풀이합니다.
3. **화살표(→)는 순서를 보여 줄 때만.** 코드 진행(C → G → Am), 신호 흐름(신스 → 필터 → 앰프), 위젯 조작 순서에만 쓴다. "그래서", "~가 된다"를 대신하지 않는다.
   - ✗ 4음 → 3음으로 풀리며
   - ○ 4음이 3음으로 내려가며 풀립니다
4. **영어 병기는 처음 한 번, 필요할 때만.** 장비나 DAW 화면에서 영어로 보게 되는 이름(Cutoff, Ratio, Attack)만 괄호로 붙인다. 우리말로 충분한 낱말(배음, 음량, 위상)에는 붙이지 않는다. 같은 레슨에서 두 번째부터는 붙이지 않는다.
5. **"vs"를 쓰지 않는다.** "A와 B", "A와 B의 차이"로 쓴다.
6. **가운뎃점(·) 나열은 짧게.** 코드 이름(C · F · G)처럼 원래 나열인 것만. 문장 안에서는 쉼표를 쓴다. 맞춤법에서도 가운뎃점 자리에 쉼표를 쓸 수 있다.
7. **제목을 물음으로 쓰지 않는다.** 제목은 그 절에서 알게 되는 것을 짧은 서술문이나 명사구로 쓴다 ("음 12개를 둥글게 놓아요", "네 가지 3화음"). 용어 사전의 "리버브란?"처럼 이름을 묻는 제목은 그대로 둔다.
8. **첫째, 둘째, 셋째로 세지 않는다.** 순서가 중요하면 번호 목록을 쓰고, 아니면 문단으로 쓴다.
9. **이모지와 장식 기호를 본문에 쓰지 않는다.** ✓, ✗, ★ 같은 기호는 표의 칸에서만.

## 4. 낱말

한 대상은 한 낱말로만 부른다.

| 대상 | 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| 5도권의 한 자리 | 칸 | 자리, 위치, 코드 자리 |
| 바로 옆 칸 | 옆 칸 | 이웃, 옆자리 |
| 5도권의 방향 | 시계 방향, 반시계 방향 | 시계 쪽, 오른쪽, 밝은 쪽 |
| 5도권의 고리 | 바깥 줄, 안쪽 줄 | 바깥 고리, 링 |
| 한 조의 코드 일곱 개가 모인 곳 | 묶음 (그림에서는 "색칠한 부분") | 부채꼴, 가족 |
| 코드가 소리 나는 것 | 울리다 | 재생되다, 소리가 나다 |
| 화성 기능 | 토닉, 서브도미넌트, 도미넌트 | (별명을 새로 만들지 않음) |
| 소리의 크기 | 음량 | 볼륨 (화면의 노브 이름이 Volume이면 그 노브만 "볼륨") |
| 두 음 사이의 거리 | 음정 | (음의 높이를 "음정"이라 부르지 않음) |
| 한 음의 높이 | 음높이 | 피치 (장비 노브 이름인 Pitch만 예외) |
| 곡의 후렴 부분 | 코러스 | 후렴 (이펙트 코러스와 헷갈리면 "코러스 단락") |
| 이펙트 코러스 | 코러스 이펙트 | (단락 코러스와 같은 문단이면 꼭 "이펙트"를 붙임) |

어려운 말은 쉬운 말로: 비로소 → 그제야, 상이한 → 다른, 용이한 → 쉬운, ~에 기인한다 → ~때문이다, 일회성 → 한 번, 주기적 → 되풀이되는, 경과적 → 지나가는.

외래어는 한 가지 표기로 통일한다. 신시사이저 계열은 아직 정하지 않았다(아래 「8. 정해야 할 것」).

## 5. 캡션

- 완결된 한 문장으로 쓴다. 그림에서 봐야 할 것 하나만 말한다.
- "A — B" 꼴로 쓰지 않는다. "A입니다. B합니다."로 쓴다.
- 악보 캡션에서 코드 이름 나열은 가운뎃점을 써도 된다. 뒤에 붙는 설명은 문장으로 쓴다.
  - ✗ C(도미솔) · F(파라도) · G(솔시레) · C — 동요 반주의 세 코드
  - ○ C, F, G로 동요 반주를 칩니다.

## 6. 화면 문구 (버튼, 안내, 위젯)

토스 UX 라이팅 원칙에서 SoundLab에 맞는 것만 가져왔다.

- **누르면 무슨 일이 생기는지 버튼이 말한다.** "확인"보다 "다음 칸", "같이 듣기". 소리가 나는 버튼은 동사로 쓴다 ("듣기", "울리기").
- **빈 문장을 넣지 않는다.** 제목이 이미 한 말을 설명에서 되풀이하지 않는다.
- **소리 내어 읽기 쉬운 말.** 한자어와 긴 호흡을 줄인다.
- **시키지 말고 권한다.** "꼭 ~하세요", "~하지 않으면 안 돼요" 대신 "~해 보세요".
- **영어 라벨은 장비에 실제로 적힌 것만.** "Waveform · 파형"처럼 영어와 한국어를 나란히 쓰는 라벨은 한쪽으로 정한다(아래 「8. 정해야 할 것」).

## 7. 고치는 순서와 심각도

1. `npm run copy:lint`로 걸리는 표현을 찾는다.
   - **오류**: 한 번만 나와도 고친다. 번역투, 이중 피동, 상투적 맺음말, 합니다체 안의 해요체.
   - **경고**: 한두 번은 괜찮고, 한 문단에 겹치면 고친다. 줄표, 굵은 글씨, 화살표, 영어 병기, 잡초 낱말.
   - **참고**: 기계로는 판단이 어려워 사람이 본다. 비유로 여는 문단, 셋으로 맞춘 나열, 같은 어미 연속.
2. 사실(수치, 음이름, 코드 이름, 링크)은 그대로 두고 표현만 고친다.
3. 소리 내어 읽는다. 걸리는 곳, 같은 어미가 세 번 이어지는 곳을 고친다.
4. 고친 뒤 수치와 주어가 바뀌지 않았는지 원문과 대조한다.
5. 검사기가 아무것도 안 잡아도 끝이 아니다. 걸리는 것이 없는데 어색하면 3번으로 돌아간다.

## 8. 정해야 할 것

- **신시사이저 표기.** 표준국어대사전 표기는 "신시사이저"다. 지금 본문에는 신디사이저 12건, 신서사이저 3건, 신스 38건, 허브 이름 "신디시스"가 섞여 있다. 규범(신시사이저)과 관용(신디사이저) 중 하나를 고르고, 줄임말 "신스"를 어디까지 쓸지 정한다.
- **영어 라벨.** 위젯의 "Waveform · 파형", "Spectrum · 실제 들리는 음" 같은 라벨을 한국어만 남길지, 영어를 작게 둘지.
- **중급과 고급 본문 말투.** 지금은 합니다체. 해요체로 바꿀지.

## 9. 적용 현황
