# 도식 그림체 규칙 — 선 도면형

> 2026-11-11 결정. 후보 3종(위젯 연장형 · 선 도면형 · 소프트 블록형) 중 **선 도면형**을 기본으로,
> 건반 테두리만 위젯처럼 옅게.

## 원칙

1. **선으로 그린다.** 채워진 것은 만지는 위젯, 선으로 그린 것은 읽는 그림.
2. **강조색은 하나.** 기본은 잉크색 + 보라. 색을 더 쓰는 것은 색이 곧 의미일 때만
   (화성 기능 T·S·D, 경고 = 빨강).
3. **같은 정보를 두 번 그리지 않는다.** 막대와 꺾은선을 겹치지 않는다.
4. **실물은 실물처럼.** 흰 건반은 흰색, 검은 건반은 잉크색.
5. **글자가 닿으면 실패.** 만들 때마다 빌드해서 스크린샷으로 확인한다.

## 값 (`src/components/doc/fig/colors.ts`)

| 용도 | 값 |
|---|---|
| 주 선 · 검은 건반 · 본문 글자 | `ink` #2d2d4a, 1.5px |
| 보조 선 · 덜 중요한 테두리 | `ink3` #a0a0c0, 1.5px |
| 건반 테두리 | `keyLine` #cdcde0, 1px |
| 눈금선 | `line` #e2e2f0, 1px (점선 쓰지 않음) |
| 강조 | `violet` #7c3aed (선·점), `violetG` #ede6fd (옅은 채움) |
| 구역 표시 | `surf` #f0f0f8 |
| 경고 | `D` #dc2626 |

## 글자

| 역할 | 크기 · 서체 |
|---|---|
| 도식 안 제목 | 14 · Space Grotesk 700 |
| 항목 이름 | 12 · Pretendard 600 · ink |
| 숫자 · 음이름 범위 · 단위 | 10 · JetBrains Mono · ink5 |
| 보조 설명 | 10 · Pretendard · ink5 |
| 캡션 | 12.5px · ink-500 (Fig.astro) |

글자 색은 ink 또는 ink5만. ink3(연회색)는 글자에 쓰지 않는다.

## 부품

- **음 표시**: 지름 20 원 + 음이름. 채움(보라) = 주인공, 고리(잉크) = 바탕.
  검은 건반 위에서는 흰 테두리.
- **범위**: 8px 둥근 선 + 옆에 모노 글자(`C5–A5 · 설명`). 오른쪽이 넘치면 왼쪽에.
- **막대**: 모서리 4, 흰 채움 + ink3 테두리. 강조 막대만 violetG 채움 + violet 테두리.
- **축**: 바닥선 ink 1.5px, 눈금 숫자는 모노 10.
- **주석 괄호**: violet 1.5px ㄷ자 선, 위에 이름(12/600) · 그 위에 모노 보조(10).

## 소리 나는 도식

도식에는 "눌러서 확인"만 넣는다. 값을 바꿔 가며 실험하는 것은 위젯의 일(슬라이더는 도식에 넣지 않음).

- **표시**: 카드 아래 구분선 + 재생 버튼(`.sl-fig-play`) + 한 줄 안내(`.sl-fig-hint`). 이 줄이 있으면 누를 수 있는 도식.
  `Fig.astro`의 `controls` 슬롯에 넣는다.
- **눌러서 듣기**: 요소에 `data-play`(MIDI 목록), `tabindex`, `role="button"`, `aria-label`. Enter·Space로도 동작.
- **재생 따라가기**: 울리는 요소에 `.is-on` — 자기 색을 16% 섞은 채움 + 테두리 2.5px. 다시 누르면 멈춤.
- **오디오**: `src/lib/figaudio.ts` — 페이지당 AudioCore 하나(`figCore`), 한 번에 한 도식만 재생(`figClaim`),
  재생 버튼 공용 로직(`figPlayer`: 사건 목록을 시간순 실행, 다시 누르면 멈춤).
- **박자가 중요한 소리**: 타이머는 `LEAD`(80ms) 먼저 깨워서 오디오 시각으로 예약하고, 강조는 `LEAD` 뒤에 켠다.
- **재생 길이**: 짧게 끝낸다(드럼 2마디, 스윙 4박, 템포 4초). 반복 재생은 위젯의 일.
- **가로 스크롤**: 재생 중에는 울리는 요소가 보이도록 스크롤이 따라간다(`figFollow`).
- **버튼 이름**: 재생 대상이 여럿이면 버튼도 대상마다 하나씩, 이름은 대상 이름(예: `8비트 록`, `67%`, `120 BPM`).
- 적용 (2026-11-12): ✅ ChordFlow(상자 누르기 + 순서대로) · StepGrid(재생선) · SwingFig(줄별) · BeatsFig(BPM별) ·
  KeyboardFig(건반 누르기 + 묶음별 차례로)
- ⬜ 도식과 위젯의 소리 겹침 방지(위젯 쪽 수정 필요)

## 5도권 그림

5도권은 화성 내용 전체의 공통 지도. 그림은 `src/lib/circle.ts`가 SVG 문자열로 만든다(Astro·클라이언트 공용).

- **방향 고정**: C가 항상 12시, 시계 방향 = 5도 위. 조나 근음이 바뀌어도 원은 돌리지 않는다(지도는 그대로, 모양이 움직임).
- **색 = 방향**: 근음에서 시계 쪽 음 = 보라, 반시계 쪽 음 = 파랑, 근음 = 잉크. 이 그림에서만 파랑이 '어두운 쪽'이라는 뜻을 가진다.
- **두 종류**
  - 음의 원 `chordShapeSvg` — 12음 한 줄. 코드의 음을 점으로 찍고 선으로 이은 모양. `ChordShapeFig`로 레슨에 넣는다.
  - 조·코드의 원 `circleSvg` — 바깥 장3화음 / 안쪽 단3화음 / 가장 안쪽 감3화음. 조 안의 코드(부채꼴)와 진행(화살표). 곡 스케치 코드 탭.
- **말하는 법**: "같은 종류의 코드는 같은 모양, 근음이 바뀌면 돌아갈 뿐", "시계 쪽 = 밝은 쪽, 반시계 쪽 = 어두운 쪽".
  극성·네거티브 하모니(거울)는 심화 단계에서 다룬다 — 프로젝트 문서 「5도권으로 보는 코드·모드·진행」 7장.
- 적용 (2026-11-12): ✅ 3화음 · 7화음 레슨(ChordShapeFig) · 곡 스케치 코드 탭(circleSvg)
