## 조용한 곳이 있어야 큰 곳이 커요

처음부터 끝까지 모든 악기가 꽉 차 있으면 금방 지쳐요. 좋은 노래는 **조용히 시작해서 점점 쌓다가, 코러스에서 터뜨리고, 다시 비워요.** 작은 부분이 있어야 큰 부분이 더 크게 느껴져요.

## 직접 해보기

<Callout>
오른쪽 위젯을 **재생**하고 **에너지** 슬라이더를 1부터 5까지 천천히 올려 보세요. 단계마다 파트가 하나씩 더해지며 곡이 점점 커져요. 5에서 갑자기 1로 내리면 마치 노래가 숨을 고르는 것 같아요.
</Callout>

## 밀도를 올리는 다섯 가지 손잡이

<DefList>
  <DefCard term="파트 수">패드만 → + 베이스 → + 드럼 → + 멜로디 → + 장식. 가장 직접적인 손잡이.</DefCard>
  <DefCard term="리듬의 촘촘함">베이스 온음표 → 4분 → 8분, 하이햇 8분 → 16분. 같은 파트로도 에너지가 오릅니다.</DefCard>
  <DefCard term="음역의 넓이">벌스는 중음역에 모아 두고, 코러스에서 위아래로 넓히면 소리가 커진 것처럼 들립니다.</DefCard>
  <DefCard term="하모닉 리듬">코드가 바뀌는 빈도. 2마디 → 1마디 → 반 마디로 빨라지면 추진력이 생깁니다.</DefCard>
  <DefCard term="음색의 밝기">필터를 열고, 패드를 스탭으로, 피아노를 신스로 바꾸면 같은 음도 더 밝고 세게 들립니다.</DefCard>
</DefList>

## 빌드업과 브레이크

- **빌드업** — 코러스 직전 2–4마디 동안 스네어를 4분 → 8분 → 16분으로 쪼개고, 필터를 열고, 상승음(라이저)을 더해 긴장을 쌓습니다.
- **브레이크(드롭 직전 비우기)** — 코러스 첫 박 직전에 반 박~한 마디를 완전히 비우면, 다시 들어오는 순간이 폭발처럼 들립니다.

<Callout>
에너지 **4**에서 **5**로 올릴 때 무엇이 바뀌는지 위젯의 파트 목록을 보세요. 하이햇이 16분으로, 베이스가 8분으로, 코드가 스탭으로 바뀌고 아르페지오가 더해집니다. 볼륨은 그대로인데 곡이 "커졌다"고 느끼는 이유가 이것입니다.
</Callout>
</Level>

## 에너지 곡선 설계

- **곡 전체를 한 장의 그래프로** — 단락마다 에너지를 1–5로 매겨 그려 보면 편곡의 문제가 보입니다. 첫 코러스가 이미 5라면 마지막 코러스가 올라갈 곳이 없습니다. 첫 코러스는 4, 마지막 코러스는 5로 아껴 두는 것이 정석입니다.
- **역방향 대비** — 마지막 코러스 직전에 모든 파트를 빼고 보컬과 피아노만 남기는(브레이크다운) 기법은, 밀도를 극단적으로 내렸다가 올리는 대비로 클라이맥스를 만듭니다.
- **보이지 않는 밀도** — 셰이커, 패드, 리버브 테일처럼 따로 들리지 않는 층이 곡의 "꽉 찬 느낌"을 만듭니다. 이런 층은 단락이 바뀔 때 빼고 넣기만 해도 체감 에너지가 크게 달라집니다.
- **다이내믹과 믹스** — 편곡의 밀도 변화가 충분하면 믹싱에서 볼륨 오토메이션을 크게 할 필요가 없습니다. 반대로 컴프레션과 리미팅을 과하게 걸면 편곡이 만든 굴곡이 평평해집니다(→ [컴프레서](/learn/mixing/compressor/)).
</Level>
